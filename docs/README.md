# 옥천 공공임대 API 데이터 안내

이 문서는 LH 분양임대공고문 조회 API(공공데이터포털 15058530)와 공고별 공급정보 API(15056765)에서 확인한 옥천 관련 예시 데이터의 필드를 설명합니다.

## 확인용 파일과 범위

- [okcheon-lh-api-sample.json](okcheon-lh-api-sample.json): 프로그램에서 읽을 수 있는 표준 JSON입니다.
- [okcheon-lh-api-sample.jsonc](okcheon-lh-api-sample.jsonc): 각 항목 옆에 설명 주석을 단 확인용 파일입니다. 표준 JSON 파서로는 읽을 수 없습니다.

두 파일은 API의 전체 응답을 그대로 저장한 것이 아닙니다. 공고 목록에서 확인한 공고를 골라 `notice`에 넣고, 해당 공고의 공급정보 중 옥천 단지의 행만 `supplies`에 모아 재구성했습니다. 원본 응답의 검색 조건·응답 헤더와 다른 지역 공급 행은 포함하지 않습니다. 행의 필드와 값은 조회 결과를 보존합니다.

조회 시각은 **2026-11-10 16:48:41 한국시간**(UTC 07:48:41), 공고일 검색 범위는 2026-01-01~2026-11-10입니다. 공고 2건과 공급정보 5행을 저장했습니다. 주소가 제공되지 않거나 지원하지 않는 원문 형식의 사업은 빠질 수 있으며, 이 파일이 모든 옥천 공고를 포함한다는 뜻은 아닙니다. 이후 변경 사항은 자동으로 반영되지 않습니다.

## 파일의 전체 구조

| 항목 | 자료형 | 설명 |
| --- | --- | --- |
| `description` | 문자열 | 파일에 담긴 자료의 간단한 설명입니다. |
| `queried_at` | 문자열 | 조회 시각입니다. 끝의 `Z`는 UTC를 뜻하며 한국시간은 9시간을 더합니다. |
| `notice_date_range.from`, `to` | 문자열 | 공고일 검색 시작일과 종료일입니다. 형식은 `YYYYMMDD`입니다. |
| `notice_count` | 숫자 | 파일에 저장한 공고 수입니다. |
| `supply_count` | 숫자 | 파일에 저장한 옥천 단지 공급정보 행 수입니다. |
| `results` | 배열 | 공고별 묶음입니다. 한 항목에 `notice` 하나와 `supplies` 배열이 있습니다. |
| `notice` | 객체 | 공고 목록 API에서 반환한 한 공고의 필드입니다. |
| `supplies` | 배열 | 같은 공고의 공급정보 중 옥천 단지에 해당하는 행입니다. 한 단지에도 주택형이나 대상에 따라 여러 행이 있을 수 있습니다. |

예를 들어 옥천장야2 공고는 `notice` 하나에 주택형별 `supplies` 세 행이 연결됩니다. 충북남부권 행복주택은 여러 지역이 포함된 통합공고지만 이 파일에는 옥천삼양 공급행 두 개만 있습니다.

## 공고 정보: `notice`

API에서 반환한 값은 날짜·건수·코드를 포함해 문자열입니다. 아래 값은 파일에 담긴 사례이며, 모든 공고가 같은 코드를 갖는다는 뜻은 아닙니다.

| 필드 | 예시 | 설명 및 사용 시 주의점 |
| --- | --- | --- |
| `PAN_NM` | 옥천장야2 국민임대주택 예비입주자 모집공고(2026.07.15) | 공고 제목입니다. 제목만으로 공급 지역을 확정할 수 없습니다. 통합공고는 제목에 옥천이 없어도 옥천 공급이 포함될 수 있습니다. |
| `PAN_ID` | `2015122300020408` | LH의 공고 식별자입니다. 숫자처럼 보여도 문자열로 보존합니다. 목록과 공급정보를 연결할 때 다른 구분 코드와 함께 사용합니다. |
| `PAN_NT_ST_DT` | `2026.07.15` | 공고일입니다. 화면에 공고일로 표시할 수 있습니다. |
| `PAN_DT` | `20260715` | 이 예시에서는 공고일이 구분자 없는 형식으로 제공됩니다. 다른 형식의 `PAN_NT_ST_DT`와 구분해 원본을 보존합니다. |
| `CLSG_DT` | `2026.07.28` | API가 제공한 공고 마감일입니다. 대상·순위·단지별 정확한 접수 종료 시각을 대신하지 않습니다. |
| `PAN_SS` | `접수마감` | 조회 당시 LH가 제공한 공고 상태입니다. 저장 시점 이후 변경될 수 있습니다. `공고중`만으로 실제 신청이 진행 중이라고 단정하지 않습니다. |
| `CNP_CD_NM` | `충청북도` | 광역 지역명입니다. 옥천군 여부를 이 필드 하나로 판별할 수 없습니다. |
| `UPP_AIS_TP_CD` | `06` | 상위 주택 유형 코드입니다. 이 예시는 임대주택입니다. |
| `UPP_AIS_TP_NM` | `임대주택` | 상위 주택 유형명입니다. |
| `AIS_TP_CD` | `07`, `10` | 세부 유형 코드입니다. 이 예시에서 각각 국민임대와 행복주택에 해당합니다. |
| `AIS_TP_CD_NM` | `국민임대`, `행복주택` | 세부 유형명입니다. 상위 분류가 임대주택이라고 해서 모두 행복주택은 아닙니다. |
| `SPL_INF_TP_CD` | `062`, `063` | 공급정보 유형 코드입니다. 해당 공고의 공급정보 API를 조회할 때 사용합니다. |
| `CCR_CNNT_SYS_DS_CD` | `03` | LH 연계 시스템 구분 코드입니다. 공고 식별 및 공급정보 조회에 함께 사용합니다. |
| `DTL_URL` | LH 청약플러스 상세 URL | 원문 공고 상세 페이지입니다. 신청 전에 첨부 공고문과 정정·취소 여부를 확인합니다. |
| `DTL_URL_MOB` | LH 청약플러스 상세 URL | 모바일용 상세 URL입니다. 이 예시에서는 일반 URL과 같습니다. |
| `ALL_CNT` | `959` | 해당 공고 목록 API 검색 결과 전체 건수입니다. 검색 조건 및 조회 시점에 따라 달라지며 옥천 공고 수가 아닙니다. |
| `RNUM` | `366` | 검색 결과 안의 순번입니다. 정렬·검색 결과가 바뀌면 달라질 수 있으므로 식별자로 쓰지 않습니다. |

## 공급정보: `supplies`

각 행은 공고에 속한 단지·주택형·공급 대상 단위의 정보입니다. 면적과 세대수도 API에서는 문자열로 반환됩니다. 화면이나 계산에서 숫자로 변환할 때는 빈 값과 비숫자 값을 별도로 처리하고 원본 값을 보존해야 합니다.

| 필드 | 예시 | 설명 및 사용 시 주의점 |
| --- | --- | --- |
| `SBD_LGO_NM` | `옥천삼양 행복주택` | 단지명입니다. 소재지 확인에 활용할 수 있지만 단지명만으로 주소를 확정하지 않습니다. |
| `HTY_NNA` | `21형 청년` | 주택형 이름이며 공급 대상이 함께 들어갈 수 있습니다. 숫자로만 취급하면 `청년` 같은 정보가 사라집니다. |
| `DDO_AR` | `21.3` | 전용면적(㎡)입니다. 이 예시는 21.3㎡입니다. |
| `SPL_AR` | `34.6247` | 공급면적(㎡)입니다. 전용면적과 다른 값이며 원본 소수 자릿수를 보존합니다. |
| `HSH_CNT` | `78` | 해당 공급 행의 세대수입니다. 이번 모집 수나 현재 빈집 수와 구분합니다. |
| `NOW_HSH_CNT` | `25` | 해당 공고에서 이번에 모집하는 수입니다. 예비입주자 모집이 포함될 수 있으며 현재 빈집 수를 의미하지 않습니다. |
| `LS_GMY` | `공고문 참조` | 임대보증금 안내입니다. 이 예시에서 금액은 제공되지 않았으며 `공고문 참조`는 0원이 아닙니다. |
| `RFE` | `공고문 참조` | 월임대료 안내입니다. 이 예시에서 금액은 제공되지 않았으며 정확한 금액과 전환 조건은 공고문을 확인해야 합니다. |

| 공고 | 조회 당시 상태 | 공고일 / 공고 마감일 | 옥천 공급정보 |

이 예시에는 상세 주소, 대상별 소득·자산·무주택 기준, 제출서류, 정확한 대상별 접수 시작·종료 시각이 별도 필드로 없습니다. 옥천 소재지 확인에는 API 목록 외에 LH 공식 상세의 주소를 대조했습니다. 실제 신청 판단과 정확한 비용·일정은 각 공고의 `DTL_URL`에서 첨부 공고문과 변경사항을 확인해야 합니다.
